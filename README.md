# 战略配备英雄 / STRATAGEM HERO

手机端离线战备输入训练器。操作方式、音效与基础交互来自
[HDWearStrategy](https://github.com/lihaoyuan114/HDWearStrategy)，战备名称、图标与初始数据来自
[HD2-Stratagem-Hero-Mobile](https://github.com/ILCNa/HD2-Stratagem-Hero-Mobile)。1.2 版的经典模式与
效果模式按 [StratagemHero_Effect](https://github.com/bocai-bca/StratagemHero_Effect) 的 Godot 实现
重写规则、时长与计分；战略配备名称与呼叫代码参照
[Helldivers Wiki](https://helldivers.wiki.gg/zh/wiki/%E6%88%98%E7%95%A5%E9%85%8D%E5%A4%87) 校正，
共 119 条。原生 Android Canvas 实现，不依赖 WebView / Capacitor，可完全离线游玩。

## 安装

APK：`dist/StratagemHero-1.2.apk`（约 7.9 MB，Android 8.0+，minSdk 26，targetSdk 34）

```bash
adb install -r dist/StratagemHero-1.2.apk
```

也可以把 APK 传到手机后点击安装，需要允许“安装未知应用”。当前包使用本地调试证书签名
（`sign/debug.keystore`），可直接侧载；若要上架应用商店，请换成自己的发布证书重新签名。
从 1.0 升级会保留最高分设置，但旧版的“标准演练 / 英雄回合”记录不再显示。

## 游戏模式

主菜单有三个页签：经典模式、效果模式、自由呼叫。经典与效果的规则、初始时间、回复速度和结算
方式均按 StratagemHero_Effect 复刻；效果模式还可在开局前开启“一错即死”。

### 经典模式

每回合从 15 秒开始，第 N 回合的实际上限为 `15 / N^0.3` 秒；目标数为
`clamp(int((N+4)/1.3), 3, 30)`，即第 1 回合 3 个、第 2 回合 4 个、第 3 回合 5 个，之后逐渐增加，
最多 30 个。回合一开始就装填第一个目标，没有额外的准备页。

- 每完成一个目标，立刻按该战备的箭头数 × 5 加分。
- 完成目标后时间向本回合上限回复，每次回复 `2.5 / sqrt(N)` 秒；只有未满上限时才会回复。
- 一回合的目标全部完成时，先额外 +2.5 秒，再结算本回合：
  - 箭头奖励：本回合完成的箭头总数 × 5；
  - 时间奖励：`int(剩余时间 / 上限 × 100)` 分，剩余时间可以超过上限，因此可能高于 100；
  - 完美奖励：本回合没有按错时 +100 分。
- 按错只清空当前目标的输入进度，并在 0.4 秒内拒绝输入；不扣时间也不扣分，但会失去本回合的
  完美奖励。屏幕边缘的红色闪烁就是这个 0.4 秒的提示。
- 结算画面停留 3.5 秒，下一回合准备 1.25 秒；倒计时归零时本局结束。
- 最高分记录键为 `classic`。

### 效果模式

开局前进入效果设置页：选择五种效果之一，可开关“一错即死”，再开始 3 秒倒计时。
无特殊效果、默写和多行从第 1 回合开始，回合上限按 `8 / N^0.15` 秒递减，每完成一行时间按
`4 / sqrt(N)` 向本回合上限回复（默写 ×6）。这些模式回合结束时结算时间奖励
`int(剩余时间 / 上限 × 10)` 与完美奖励（本回合箭头数），随后休息 4.3 秒进入下一回合。长城固定
15 秒、终端固定 20 秒，二者没有回合，按各自规则回复时间。按错会按模式清空当前行（多行只清
该行，长城不清进度），并在 0.6 秒保护期内不重复扣时。

| 效果 | 初始时间 / 第 1 回合 | 回合目标数 | 特点 |
| --- | --- | --- | --- |
| 无特殊效果 | 8 秒 | `clamp(int(N×0.5)+2, 3, 16)` = 3 | 单行战备，显示完整箭头 |
| 默写模式 | 48 秒（8 秒 × 6） | 3 | 隐藏未输入部分的箭头，回复速度与时间上限都 ×6 |
| 多行模式 | 8 秒 | `clamp(int(N×0.5)+2, 8, 28)` = 8 | 4 条战线共享牌堆 |
| 长城模式 | 15 秒 | 无回合 | 连续 8 个方向，按错不清进度 |
| 终端模式 | 20 秒 | 无回合 | 模拟终端长序列，逐行加长 |

具体规则：

- **无特殊效果**：单行战备；完成一行加该行箭头数，时间向 `8 / N^0.15` 回复。按错扣 0.3 秒
  （保护期结束后才生效），清空当前行。
- **默写模式**：与无特殊效果相同，但只显示当前已输入部分的箭头，未输入部分留空；时间上限、
  回复量和按错惩罚都乘以 6，所以第 1 回合有 48 秒、按错扣 1.5 秒。
- **多行模式**：屏幕同时有 4 条战线，每条战线各取一个战备，共用剩余牌堆。完成一条战线会加分、
  回复时间并从牌堆补位；牌堆为空且 4 条战线全部完成时本回合结束。输入会优先送入已经开始输入
  的战线；若同一拍只有错误行，才扣 0.3 秒并失去完美，任一战线正确则不扣全局时间。
- **长城模式**：屏幕一次显示 8 个方向，只能从最左侧未输入的箭头开始。正确后该箭头消失并在末尾
  补一个随机方向，完成箭头数 +1，时间按 `(1 / max(1, 完成数^0.8)) × 15` 向 15 秒回复；按错只
  闪烁并扣 0.75 秒，不会清空已完成的进度。没有回合，时间归零即结束，结算显示完成箭头、坚持
  时间与速度。
- **终端模式**：屏幕显示一条终端序列，第 n 行长度为
  `clamp(int(log(n)×1.5)+5, 5, 12)`，即 5、6、7……逐行变长。完整输入一行加该行箭头数，时间向
  `15 × clamp(1.5/(已完成行数+1), 0, 1)` 回复；按错清空当前行并扣 0.75 秒。没有回合，时间归零
  即结束，结算显示通过行数、完成箭头与速度。
- **一错即死**：效果模式的附加开关，任意一次按错立即结束本局；时间惩罚规则仍然生效，只是通常
  已经不需要了。开启后与同一种效果共用最高分记录，记录键为
  `effect_none` / `effect_dictation` / `effect_greatwall` / `effect_multilines` /
  `effect_terminal`。
- 效果模式的结算页显示所选效果名、最终得分、回合或行数、完成箭头、速度与历史最高；长城和终端
  不显示回合。

### 自由呼叫

无计时、无分数。完整输入某个战备的代码即完成呼叫；输入前缀会高亮可匹配的战备。
从主菜单选择自由呼叫会先进入图鉴，查看全部 119 条战备代码；图鉴右上角的“盲呼”或详情页的
“开始盲呼”会进入自由呼叫。完成呼叫后卡片揭示 2.6 秒并短暂锁定输入，避免连按误触。

## 声音

- 背景音乐（`hero_loop`）在倒计时结束进入游戏时开始，跨回合持续播放；暂停、切到后台、
  退出任务或结算时暂停或停止，继续游戏时从暂停处恢复。经典、效果与自由呼叫共用同一套循环。
- 每成功完成一条战备，都会先播放成功音，再播放该战备对应的 Mission Control 呼叫语音：
  支援武器、背包装备、哨戒炮、防御工事、载具/外骨骼、飞鹰与轨道火力等按类型分组；
  重新补给、增援、SOS、飞鹰重新武装、地狱火炸弹与任务目标另有专用语音。每组有 1–4 条
  随机变体，避免连续重复。
- 清空经典模式一回合或效果模式一轮时追加通关音；时间耗尽或一错即死时播放失败音。
  效果模式的长城与终端是逐符号/逐行输入，不对应具体战备，因此不播放呼叫语音，只保留
  常规输入、成功与失败音效。
- 设置中的“语音播报”独立于“音效 / 触感”开关；关闭音效会同时停止背景音乐，重新开启后
  在游玩界面恢复。
- 设置页可分别拖动“背景音乐”和“语音音量”滑杆，范围 0%–200%，按轨道位置取整并立即保存。
  100% 保持 1.2 之前的响度，200% 为两倍：语音资源在打包前统一做了 +6.02 dB 预增益，播放
  基准相应降到 0.45，因此 100% 不会变响，而 200% 能真正达到两倍。
- 通关音有 A、B 两条，播放器会记住上一条并强制交替，连续两回合不会重复同一首；同时把
  SoundPool 并发数提高到 10，并让通关音以更高优先级播放，避免它被连发的输入音效挤掉。

## 横屏与安全区

- 跟随系统自动旋转，不提供手动方向锁定；竖屏和横屏都有完整布局。
- 竖屏以 450 × 760 设计单位等比缩放并居中；横屏以 1280 × 520 设计单位缩放，舞台在左、
  四向圆盘在右。更高或更宽的屏幕会保留更多留白，不会拉伸变形。设置页在横屏会按可用高度
  压缩行高，五组开关/滑杆、三行提示与返回按钮始终分开排列，短横屏也不会重叠。
- 全面屏与刘海屏读取左、上、右、下四边安全区，菜单、游戏、结算、图鉴和设置都不会进入挖孔
  或圆角区域。
- 游玩中旋转屏幕会自动暂停并弹出战术暂停；倒计时页旋转不会暂停，倒计时会继续走。

## 操作

- 底部四向圆盘在按下的瞬间就输入，不必等手指抬起；圆盘以外的地方也可以滑动。关闭“四向键盘”
  后圆盘隐藏，改成全屏滑动，卡片自动放大。
- 滑动一笔只输入一个方向。横向位移超过约 16 个设计单位、纵向超过约 24 个单位即触发；抬手时
  改用略低的 12 / 20 阈值补一次，所以快速一甩也能被接住。斜向滑动按主轴判定，不会作废。
- 圆盘上的扇区在按下时亮起，正确输入后会短暂高亮，方向残影 0.45 秒内淡出。
- 顶部左侧喇叭快速开关音效与触感，右侧齿轮进入设置，右上角问号进入作战手册；顶部中央按钮暂停。
- 暂停菜单可继续、重新开始、进入设置或退出任务。系统返回键或返回手势优先回到上一界面；如果
  返回手势抢走了一次滑动，会按滑动方向补上一次输入。

## 构建

需要 JDK 17、Android SDK Platform 34、Build-Tools 34.0.0。本机工具链路径见
`tools/build_apk.sh` 顶部的默认值，可用 `JAVA_HOME` / `ANDROID_HOME` 覆盖：

```bash
JAVA_HOME="/path/to/jdk17" ANDROID_HOME="/path/to/android-sdk" bash tools/build_apk.sh
```

脚本流程：aapt2 编译/链接资源 → javac（Java 8 字节码）→ D8 → 把 classes.dex 写回 APK →
zipalign → apksigner。生成 `dist/StratagemHero-1.2.apk`（versionCode 3、versionName 1.2）并自动
验证签名。

## 已知限制

- 开发环境没有真机或 Android 模拟器，因此背景音乐、通关音与 65 条呼叫语音的实际播放、
  混音、两倍音量下的失真和触感强度未在硬件上试听；只验证了 OGG 容器头、资源打包、APK
  签名与规则/映射测试，交互与布局通过 Robolectric 测试和截图验证。不同厂商手势导航和
  自动旋转的最终表现也未在硬件上验证。
- 竖屏按 450 × 760、横屏按 1280 × 520 设计单位适配，手机与常见平板可用；超宽或超矮屏幕会保留
  留白，未做平板专属分栏。
- 效果模式的高分记录按“效果类型”分别保存，“一错即死”与同效果共用一条记录。原版要求至少启用
  16 个战备才记录最高分；本应用固定 119 个全开，因此恒满足该条件。
- 105 条基础战备数据截至 HD2-Stratagem-Hero-Mobile 2026-07-09 的快照；名称/代码与 14 条补充
  战备取自 Helldivers Wiki 2026-10-29 的快照，后续游戏更新可能需要重新同步。
